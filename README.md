## Fieldwork

### Urban Immersion Fieldwork | Kochi, Kerala

Built an Urban Observatory System spanning transport, health, education, migrant labour, and municipal services. The project combined field observations, stakeholder interviews, and secondary data into a reference dataset and public dashboard for understanding urban mobility and service conditions.

- [Dashboard and supporting documents](https://drive.google.com/file/d/1MR5Zc2j3flllPMF0_-JlFqgt3Q-qcMDV/view?usp=sharing)

### Rural Immersion Fieldwork | Sangamner, Maharashtra

Collected and analyzed household- and village-level field data across drought-prone regions to map water-stress patterns. The work used structured surveys, on-ground data collection, and case-study analysis to examine rural livelihoods, resource access, and local development challenges.
